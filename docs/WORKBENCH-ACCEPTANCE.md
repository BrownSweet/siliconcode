## 真实发现与平台调整

- 初始模型调用漏填 `checks`，工具返回参数错误；模型随后修正。现已明确：字段必填，未知命令用空数组，不用 echo/true 占位。
- 原始通配符命令失败暴露了执行器契约不清晰；现于提示、工具 schema 和文档明确原生 argv 限制及版本修订方式。
- 模型读取项目外 npm 日志被文件工具拒绝，后续任务继续；没有放宽 workdir 边界。
- 只读审查模型反复查找运行日志；现明确审查检查代码与覆盖，服务随后执行测试/打包并记录证据。
- 真实调用中已观察到工具错误恢复、审批、停止保留文件、审查驱动修复。网络超时/断流/重启恢复等故障路径由故障注入测试覆盖，本次未人为制造官方服务故障。
